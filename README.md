# 🎙️ Murf AI Voice Agent – Day 5  
**Sales Development Representative (SDR) Voice Agent**

This repository contains my submission for **Day 5** of the Murf AI Voice Agents Challenge.  
For this task, I built a voice-based **SDR agent** that can:

- Answer company/product FAQs  
- Understand user needs and respond accordingly  
- Collect lead details naturally  
- Generate an end-of-call summary  
- Store everything in structured JSON
